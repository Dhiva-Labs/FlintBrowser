# Flatpak

`com.dhivalabs.flint.yml` (standard edition) and `com.dhivalabs.flintplus.yml`
(Flint Plus) package Flint for Flatpak on the `org.freedesktop.Platform`
25.08 runtime with the `org.electronjs.Electron2.BaseApp` base app, whose
zypak wrapper runs Chromium's sandbox inside the Flatpak sandbox.

## How CI builds it

The `distros` job in `.github/workflows/build-installers.yml` unpacks each
edition's `.deb` (built by the `linux` job) into an installed tree
(`packaging/linux-distros/deb-tree.sh`). The `flatpak` job unpacks that tree
into `packaging/flatpak/tree/` and runs flatpak-builder on the edition's
manifest in the `ghcr.io/flathub-infra/flatpak-github-actions:freedesktop-25.08`
container, once per architecture (x86_64 and aarch64, each on a native
runner). The result is a single-file bundle,
`<package>-<version>-<arch>.flatpak`, whose runtime repository is Flathub.

The `flatpak-test` job then installs that bundle on a plain Ubuntu runner,
pulling the runtime and base app from Flathub, and runs it
(`test-bundle.sh`): ldd of every ELF file in the app, the in-app smoke suite
under Xvfb, and a plain start that must stay up for 20 seconds.

The newest `<release>` in each metainfo file must match the version in
`package.json`; the `flatpak` job fails otherwise, so add the release there
when bumping the version.

## Installing a bundle

```sh
flatpak remote-add --user --if-not-exists flathub https://dl.flathub.org/repo/flathub.flatpakrepo
flatpak install --user ./flint-browser-<version>-x86_64.flatpak
flatpak run com.dhivalabs.flint
```

Flint Plus is `flint-browser-plus-<version>-<arch>.flatpak`, app id
`com.dhivalabs.flintplus`.

Permissions: network, sound, GPU, notifications, and the Downloads folder
(downloads are saved there; other files go through the file chooser portal).

## Flathub

Flathub builds from source, so a submission would replace the `tree`
directory source with the repository at a release tag plus the npm
dependencies generated by `flatpak-node-generator`, and run electron-builder's
`dir` target inside the manifest (with the adblock engine built in a
separate step, since the build sandbox has no network).
